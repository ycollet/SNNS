ART2 Update Functions

 

Again two update functions for ART2 networks have been implemented:

  • ART2_Stable
  • ART2_Synchronous.

Meaning and usage of these functions are equal to their equivalents of the ART1 model. For both of them the parameters , a, b, c and have to be defined in the row of update parameters in the control panel.
