Mkhead

 

This program writes a SNNS pattern file header to stdout. This program can be used together with mkpat and mkout to produce pattern files from raw files in a shell script. Synopsis: mkhead <pats> <in_units> <out_units>

where: 

 
		  pats 		 are the number of patterns in the file


		  in_units 		 are the number of input units in the file


		  out_units 		 are the number of output units in the file
