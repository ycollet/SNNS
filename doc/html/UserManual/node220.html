The Kohonen Init Function

Before a SOM can be trained, its weights have to be initialized using the init function Kohonen_Weights. This init function first initializes all weights with random values between the specified borders. Then it normalizes all links on a per-unit basis. Some of the internal values needed for later training are also set here. It uses the same parameters as CPN_Weights (see section ).
