Loading and Saving Patterns

    Patterns are combinations of activations of input or output units. Pattern files, like nets, are handled by the SNNS kernel. Upon loading the patterns, it is not checked whether the patterns fit to the network. If the number of activation values does not fit to the number of input, resp. output units, a sub-pattern shifting scheme has to be defined later on in the sub-pattern panel. See chapter for details. The filename of the patterns loaded last is displayed in the control panel.

Note: The activation values are read and assigned to the input and output units sequentially in ascending order of the unit numbers (see above).
