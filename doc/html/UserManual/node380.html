Definition of the Grammar

 

The Grammar defining the interface is listed in a special form of EBNF.

  • Parts between square brackets SPM_amp[]& are facultative.

  • SPM_amp|& separates alternatives (like with terminal symbols).

  • SPM_ampx& means, that x may occur zero or more times.

  • CSTRING is everything that is recognized as string by the C programming language.
