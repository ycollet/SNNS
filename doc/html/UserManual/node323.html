Overview

There are the following tools available to ease the use of SNNS: 

 
 analyze: 		 		 analyzes result files generated by SNNS to test the classification


		 		capabilities of the corresponding net


 bignet: 		 		  feedforward network generator


 Convert2snns: 		 		  pattern conversion tool for Kohonen Networks


 feedback-gennet: 		 		 generator for network definition files


 mkhead: 		 		 writes SNNS pattern file header to stdout


 mkout: 		 		 writes SNNS output pattern to stdout


 mkpat: 		 		 reads 8 bit rawfile and writes SNNS pattern file to stdout


 netlearn: 		 		 backpropagation test program


 netperf: 		 		benchmark program


 pat_sel: 		 		produces pattern file with selected patterns


 snns2c: 		 		compiles an SNNS network file into an executable C source.
