Kernelrpc

Kernelrpc has the following options:

  • uid <xguirpc.user-id>: the user-id of the xguirpc user,

  • host <xgui_rpc_host>: the host-name of the xguirpc,

  • program <xgui_program_number>: the program number under which the xguirpc is registered at the portmapper,

  • version <xgui_version_number>: the version number under which the xguirpc is registered at the portmapper,

  • type <type>: kernel type (normal or masters),

  • net <net-name>: the name of a network file that is to be loaded,

  • pat <pat-name>: the name of a pattern file that is to be loaded. This option may be given more than once.

If kernelrpc is started without any options the kernel will wait a short period of time. If there is no connection to an xguirpc the kernelrpc will be aborted. The default waiting time is set to 15 minutes. The simplest way to start kernelrpc is with the help of the New panel of the rpc module, because all options are set automatically. It is possible to run up to 10 kernelrpcs at the same time on one computer.

In some networks problems occur, caused by the domain name. If NIS (SUN Yellow pages) is activated, the function getdomainname does not deliver the correct domain name. However, this problem can be solved, if the environment variable DOMAINNAME is set to the correct domain name.

Example: On our Sun workstations getdomainname returns infra instead of
informatik.uni-stuttgart.de. To solve this problem, we type: setenv DOMAINNAME informatik.uni-stuttgart.de. The best way to achieve this is to add the above line to the .cshrc file.
