ClippHebb

  The ClippHebb algorithm is almost the same as the Hebb algorithm, the only difference is that all weights can only be set to 1 and 0. After the activation for the neurons is calculated, all weights > 1 will be set to 1. As mentioned in the ClippHebb algorithm is a learning algorithm.
