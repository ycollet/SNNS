Fixed Size Patterns

   

When using fixed size patterns, the number of input and output values has to match the number of input and output units in the network respectively for training purposes. Patterns without output activations can be defined for networks without output units (e.g. ART networks), or for test/recall purposes for networks with output units. It is possible, for example, to load two sets of patterns into SNNS: A training pattern set with output values for the training of the network, and a test pattern set without output values for recall. The switch between the pattern sets is performed with the button as described above.

Pattern definition files prior to V3.0 require output activations. Networks or patterns without output are not possible

Note: All Pattern definition files prior to V3.2 now correspond to the type fixed size!
